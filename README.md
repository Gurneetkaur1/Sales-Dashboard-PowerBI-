# Sales Dashboard – Power BI

## Project Overview
An interactive Sales Dashboard created using Power BI to analyze sales performance, trends, and key business insights.

## Key Analysis
- Analyzed 9,995 sales records
- Monitored monthly sales trends
- Analyzed sales quantity and performance
- Used interactive slicers and filters
- Created visualizations to identify business trends

## Tools & Technologies
- Power BI
- Excel
- Data Visualization

## Dashboard Features
- Interactive sales analysis
- Monthly sales trends
- Quantity analysis
- KPI-based performance tracking
- Interactive filters and slicers
